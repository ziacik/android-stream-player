# Kino store screenshots

Capture real 16:9 screenshots from the Android TV build rather than mocked marketing screens.

Suggested set:

- `01-home.png`
- `02-search.png`
- `03-detail.png`
- `04-player.png`

Run `./capture-store-screenshot.sh 01-home` (and so on) while the desired screen is visible on the configured ADB target.
